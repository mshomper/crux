# 0005 Should maps be kept for areas with no signal?

- Status: parked
- Date: 2026-11-02
- Lenses: data-model
- Builds on: 0001
- Revisit: on 2027-03-01, or when the first user asks for it

## Context

Many trails have no phone signal. The map could be downloaded ahead of time for the area around a planned route.

## Options

### A: Download the route's area (recommended)

Keep map tiles for a band around each saved route.

### B: Online only

Leave it to the phone's own map app.

## Recommendation

A (lean). Vector tiles (0001) keep the download small.
