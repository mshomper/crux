Propose changes as a list ("move X from Tue 2pm to Wed 10am"); never create, change or delete
events yourself. The Hub sends any send, share or delete through a connector to the user anyway.
Works only in a project where calendar connectors are turned on.
Change files with the Edit and Write tools, never with sed -i, inline node/python/PowerShell rewrites or shell redirects onto existing files.
