# Ollama on your second PC, used by the hub (decision 82)

Small text jobs (labels, rewording, tidying, plain drafts) can run free on the RX 9070 box and leave the main GPU to training. Everything stays on your Tailscale network. About 15 minutes.

1. **Tailscale on both PCs**, signed in to the same tailnet. On the second PC, in PowerShell: `tailscale ip -4`. That is its address, `100.x.x.x`. Its name (`pc-name.your-tailnet.ts.net`) is in the Tailscale admin page.
2. **Update the AMD Adrenalin driver** (amd.com, latest), then **install Ollama for Windows** (ollama.com/download).
3. **Pull one model.** `ollama pull gemma3:12b` (Google, 8.2 GB, fits easily). Or `ollama pull gpt-oss:20b` (OpenAI open weights, Apache 2.0, 14 GB, tight on 16 GB). Do not pull Qwen or other Chinese models (R015), and nothing ending `-cloud`: the hub refuses it, since it would leave your machines.
4. **Check it uses the GPU.** `ollama run gemma3:12b "hello"`, then in a second window `ollama ps`. The PROCESSOR column should say `100% GPU`. If it says CPU: update Ollama and the driver, make sure `OLLAMA_VULKAN` is not set to `0` (Vulkan is on by default in current Ollama), and on an older Ollama try `OLLAMA_VULKAN=1`. Quit and restart Ollama after any change.
5. **Make Ollama answer on the Tailscale address only.** Quit Ollama (taskbar icon). Settings, search "environment variables", add a user variable `OLLAMA_HOST` = `100.x.x.x:11434` (your address from step 1). Start Ollama from the Start menu. Bound to that address, your home network cannot reach it at all. Do not use `0.0.0.0`: it listens on every network, and if Ollama's installer added a firewall rule open to all (unverified) your home network could then reach it. If Ollama ever fails to start because Tailscale was not up yet, start Tailscale and then quit and start Ollama again.
6. **Firewall, Tailscale only.** In PowerShell as administrator: `New-NetFirewallRule -DisplayName "Ollama on Tailscale only" -Direction Inbound -Protocol TCP -LocalPort 11434 -RemoteAddress 100.64.0.0/10 -Profile Any -Action Allow`. Then look for a rule the Ollama installer or Windows may have added for all networks: `Get-NetFirewallRule -DisplayName "*ollama*" | Format-Table DisplayName, Enabled, Direction, Action, Profile` (or Windows Defender Firewall with Advanced Security, Inbound Rules). Remove any inbound Allow rule for Ollama other than "Ollama on Tailscale only": `Remove-NetFirewallRule -DisplayName "<its exact name>"`. If Windows asks about Ollama on a network the first time, choose Cancel.
7. **Test from the main PC.** `curl.exe http://100.x.x.x:11434/api/tags` lists the model. Then from the hub folder: `node tools/offload-live-check.mjs --provider ollama --model gemma3:12b --address http://100.x.x.x:11434` prints one line ending `ok`.
8. **Tell the hub.** Whole hub panel, Outside provider keys, Ollama box: paste `http://100.x.x.x:11434` (the line under it turns green: "Your Tailscale machine"). Under Who answers which job, pick Ollama and `gemma3:12b` for short questions and long drafts, press Done. Projects set to Local only or Any can then use it. If the PC is asleep or off, the job says "Ollama at <name> did not answer." and nothing else answers instead.

**Checked against Ollama's own docs (docs.ollama.com, ollama.com/library):** the `OLLAMA_HOST` variable and its default (127.0.0.1:11434); the Windows steps for setting it (quit, edit user variable, start again); `ollama ps` and its PROCESSOR column; Vulkan enabled by default and `OLLAMA_VULKAN=0` to turn it off; sizes and makers of gemma3:12b (8.2 GB, Google) and gpt-oss:20b (14 GB, OpenAI, Apache 2.0).

**Could not verify:** that the RX 9070 runs on the GPU in Windows (Ollama's GPU page lists the RX 9070 under Linux ROCm only; the Windows table names only RX 7000-series cards, so expect the Vulkan path and confirm with `ollama ps`); the `OLLAMA_VULKAN=1` step on older versions; whether the Ollama installer adds its own firewall rule (step 6 shows how to look for one) and the exact PowerShell firewall commands (standard Windows cmdlets, not from Ollama's docs); the Tailscale commands and names (from experience, not fetched from Tailscale's docs); speed on this card.
